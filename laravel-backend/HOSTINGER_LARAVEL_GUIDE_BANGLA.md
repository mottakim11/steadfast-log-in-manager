# Steadfast Secure Login Manager - Laravel Backend (Hostinger Guide)

এই ফোল্ডারে (`laravel-backend`) সম্পূর্ণ সিস্টেমটিকে আধুনিক **PHP 8.2+ এবং Laravel** দিয়ে তৈরি করা হয়েছে। 
আপনার পূর্ববর্তী Node.js সার্ভারের সমস্ত ফাইল অক্ষত রয়েছে এবং নতুন এই Laravel ভার্সনটি **Hostinger Shared Web Hosting** অথবা **Hostinger VPS** যেকোনোটিতে খুব সহজে হোস্ট করা যাবে।

---

## 🚀 ক্রোম এক্সটেনশনের সাথে সামঞ্জস্যতা (Extension Compatibility)
- **এক্সটেনশনে কোনো কোড পরিবর্তন করতে হবে না:** এক্সটেনশনটি পূর্বের মতোই শতভাগ কাজ করবে।
- এক্সটেনশন বা পপআপে শুধু **Admin Server URL** পরিবর্তন করে আপনার নতুন লারাভেল সাইটের URL বসাবেন:
  - লোকাল টেস্টের জন্য: `http://localhost:8000`
  - Hostinger-এ লাইভ করার পর: `https://yourdomain.com`
- **অফিস সিক্রেট কি:** আগের মতোই কাজ করবে (যেমন Mulatol Office: `sflm_off_333a45e9d85a0c8c980dbbfc23801737`)।

## 💻 ১. লোকাল কম্পিউটারে রান করার নিয়ম (Local Testing)

১. টার্মিনাল ওপেন করে `laravel-backend` ফোল্ডারে যান:
```bash
cd laravel-backend
```

২. সার্ভার চালু করতে রান করুন:
```bash
php artisan serve --port=8000
```

৩. ব্রাউজারে প্রবেশ করুন:
- **অ্যাডমিন প্যানেল:** [http://localhost:8000](http://localhost:8000)
- **লগইন তথ্য:**
  - ইউজারনেম: `admin`
  - পাসওয়ার্ড: `admin123456`

## 🌐 ২. Hostinger Shared Web Hosting-এ হোস্ট করার নিয়ম (hPanel)

হোস্টিংগারের সবচেয়ে সহজ ও সাশ্রয়ী **Shared Hosting / Cloud Hosting (hPanel)**-এ হোস্ট করতে নিচের ধাপগুলো অনুসরণ করুন:

### ধাপ ১: প্রজেক্ট জিপ (ZIP) করা
আপনার পিসির `laravel-backend` ফোল্ডারটিকে জিপ ফাইলে রূপান্তর করুন।

### ধাপ ২: Hostinger File Manager-এ আপলোড
১. Hostinger hPanel-এ লগইন করে আপনার ডোমেইনের **File Manager** ওপেন করুন।
২. আপনার ডোমেইনের রুট ডিরেক্টরিতে (সাধারণত `public_html`-এর সমান লেভেলে বা একটি ফোল্ডার তৈরি করে) জিপ ফাইলটি আপলোড করে **Extract** (আনজিপ) করুন।

### ধাপ ৩: Document Root নির্ধারণ করা
লারাভেলের সব পাবলিক ফাইল `public` ফোল্ডারে থাকে। 
- hPanel থেকে **Websites** -> আপনার ডোমেইন সিলেক্ট করে **General Settings / Redirects** বা **Change Document Root** অপশনে যান।
- Document Root সেট করুন: `public` (বা `laravel-backend/public`)।

*(বিকল্প উপায়: আপনি চাইলে `laravel-backend/public` এর ভেতরের সব ফাইল সরাসরি `public_html`-এ রাখতে পারেন এবং `index.php`-র পাথ ঠিক করে দিতে পারেন।)*

### ধাপ ৪: ডাটাবেজ কনফিগারেশন (.env)
- **SQLite ব্যবহার করলে:** কোনো কনফিগারেশন ছাড়াই সরাসরি চলবে! `database/database.sqlite` ফাইলে ডাটা সেভ থাকবে।
- **MySQL ব্যবহার করতে চাইলে:** 
  hPanel থেকে একটি MySQL Database তৈরি করুন এবং `.env` ফাইলে আপডেট করুন:
  ```env
  DB_CONNECTION=mysql
  DB_HOST=127.0.0.1
  DB_PORT=3306
  DB_DATABASE=আপনার_ডাটাবেজের_নাম
  DB_USERNAME=আপনার_ডাটাবেজ_ইউজার
  DB_PASSWORD=আপনার_ডাটাবেজ_পাসওয়ার্ড
  ```
  এরপর SSH টার্মিনাল থেকে রান করুন:
  ```bash
  php artisan migrate --seed
  ```
  *(সব ৪টি অফিস এবং ৪টি লেটেস্ট অ্যাকাউন্ট স্বয়ংক্রিয়ভাবে ডাটাবেজে যুক্ত হয়ে যাবে।)*

## 🔐 ৩. পাসওয়ার্ড সিকিউরিটি ও Secret Key

লারাভেল ব্যাকএন্ডেও হুবহু পূর্বের মতো সামরিক গ্রেডের **AES-256-GCM** এনক্রিপশন ব্যবহার করা হয়েছে।
- মূল ডিক্রিপশন কি-টি রয়েছে: `storage/data/secret.key` ফাইলে।
- ফলে আপনার বর্তমান অ্যাকাউন্টগুলোর কোনো পাসওয়ার্ড পরিবর্তিত হয়নি এবং এক্সটেনশনে কোনো প্রকার জটিলতা ছাড়াই স্বয়ংক্রিয়ভাবে ফিল-আপ হয়ে লগইন হয়ে যাবে।
