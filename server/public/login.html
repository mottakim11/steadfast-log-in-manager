📥 এক্সটেনশন ইনস্টল করার নিয়ম (Installation Guide)
1

"Download .zip" এ ক্লিক করে ফাইল ডাউনলোড ও Extract/Unzip করুন।

2

Chrome ব্রাউজারে chrome://extensions লিখে Developer mode অন করুন।

3

"Load unpacked" ক্লিক করে আনজিপ করা extension ফোল্ডারটি সিলেক্ট করুন।

4

আইকনে ক্লিক করে Server URL ও আপনার অফিসের Secret Key দিয়ে সেভ করুন।
